## 2025-02-14 - Fix Playwright XSS leading to LFI / SSRF
**Vulnerability:** The HTML-to-PDF compilation using Playwright (`pdf_compiler.py`) rendered unsanitized user-controlled HTML. This allowed attackers to inject `<script>` tags (XSS) that could execute in the browser context, enabling Server-Side Request Forgery (SSRF) and Local File Inclusion (LFI) (e.g. `fetch("file:///etc/passwd")`).
**Learning:** Headless browsers used for rendering PDFs from user input execute JavaScript and have file-system access by default. Relying on client-side constraints or just rendering HTML directly without a restrictive sandbox allows critical system access.
**Prevention:** Always implement a strict Content-Security-Policy (CSP) meta tag when rendering user-provided HTML in headless browsers, explicitly blocking local network/file access (`connect-src 'none'`) and restricting script/style sources. Alternatively, disable JavaScript execution entirely if not strictly required, and sanitize input HTML on the server.
