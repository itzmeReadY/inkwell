## 2025-02-14 - Playwright Headless PDF Generation SSRF
**Vulnerability:** Server-Side Request Forgery (SSRF) and Server-Side XSS via Playwright. Unsanitized user-provided HTML with malicious `<script>` tags, `<iframe src="...">`, or `fetch()` calls could execute JavaScript within the backend headless browser. This allowed an attacker to read local files (e.g. `/etc/passwd` via `file:///etc/passwd`) and make requests to internal services.
**Learning:** Headless browsers used for server-side generation (like PDF or screenshots) execute HTML as a real browser does. This means they are fully susceptible to XSS which rapidly elevates to Critical SSRF/Local File Disclosure if network requests and local file access are not strictly restricted.
**Prevention:** Disable unnecessary network access. Use Playwright's `page.route("**/*", handler)` to intercept and drop all network requests unless they match an explicit whitelist of required domains or protocols (e.g., specific CDNs for fonts/scripts and `data:` URIs for inline images).
