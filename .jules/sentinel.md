## 2024-10-24 - Cross-Site Scripting (XSS) in Playwright PDF Generator
**Vulnerability:** User-provided text, sizes, and colors in PDF text annotations (`_build_textbox_html`) were not escaped before being injected directly into an HTML template string. This allowed an attacker to break out of attributes or inject raw HTML, executing malicious scripts (XSS) inside the headless Playwright browser rendering the PDF.
**Learning:** Even when the final output is a PDF, if an intermediary step involves generating HTML and rendering it in a headless browser, that step is fully vulnerable to standard web attacks like DOM-based XSS or stored XSS. Furthermore, attributes in template strings like `<div style="color: {color}">` need both attribute-level escaping (e.g., breaking out with `"`) and HTML escaping (e.g., `</script>`).
**Prevention:** Always use `html.escape()` or a robust templating engine (like Jinja2) when constructing HTML strings from user input, even in backend processes like PDF generation. Ensure positional numbers (like `x` and `y`) are cast strictly to float/int to prevent attribute-breakout injection.
