## 2024-05-20 - React Re-renders in Inkwell
**Learning:** In `App.tsx`, the `updateCurrentPage` function, `handleSaveDrawing` function, and `handleUpdateTextBoxes` function are re-created on every keystroke because the `Preview` component uses inline fallback array `currentPage.textBoxes || []` and inline function references (`onUpdateMarkdown={(md) => updateCurrentPage({ markdown: md })}`). These props cause `Preview` (which manages computationally expensive markdown rendering) to re-render unnecessarily on every state update, leading to lag when typing.
**Action:** Use stable references by defining `const EMPTY_ARRAY = []` outside the component and wrap `handleSaveDrawing`, `handleUpdateTextBoxes`, and inline functions like `onUpdateMarkdown`, `onToggleEditMarkdown` in `useCallback` to prevent cascading re-renders of the expensive `Preview` component.
