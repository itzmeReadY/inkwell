## 2026-10-05 - Extracted ReactMarkdown plugins and memoized rendering block
**Learning:** Found that `ReactMarkdown` was receiving literal inline arrays for `remarkPlugins` and `rehypePlugins` in `Preview.tsx`. Since KaTeX math rendering is very expensive, re-evaluating the component tree on every property change from the parent (like `App.tsx` updating drawing modes, textboxes, tools) caused significant rendering pauses. A common React performance pitfall is passing new array references to plugins on every render.
**Action:** Extract the static `remarkPlugins` and `rehypePlugins` lists into module-level constant arrays to preserve stable references, and aggressively wrap `ReactMarkdown` with `useMemo` so it only re-evaluates when the underlying `markdown` text changes.
