## 2023-10-27 - Memoizing Expensive Markdown & LaTeX Rendering
**Learning:** In applications like Inkwell that use `react-markdown` alongside `remark-math` and `rehype-katex` for real-time mathematical formatting, the parsing and rendering process is highly CPU-intensive and blocks the main thread. When the `Preview` component containing these elements re-rendered due to unrelated state changes (like switching annotation colors or typing in plain text which triggers an `App` re-render), it caused severe typing lag and UI unresponsiveness.
**Action:** Always wrap heavy markdown and math renderer components (like `<ReactMarkdown>`) in `React.memo` (e.g., `<MemoizedMarkdown content={markdown} />`). This ensures the expensive DOM calculations and AST parsing only occur when the actual text content changes, effectively decoupling it from frequent state updates like UI styling or drawing tool selections.
