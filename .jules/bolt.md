## 2024-05-15 - ReactMarkdown Re-render Optimization
**Learning:** Passing inline arrays like `remarkPlugins={[remarkMath]}` to `ReactMarkdown` creates a new array reference on every render of the parent component. This forces `ReactMarkdown` to completely re-parse and re-render the AST (including expensive KaTeX math rendering) even when the actual `markdown` content hasn't changed. In Inkwell, typing in the raw text input caused the `<Preview>` component to re-render constantly (since parent state was updating), making typing laggy.
**Action:** Always extract static plugin arrays (`remarkPlugins` and `rehypePlugins`) outside the component to ensure stable references, and memoize the `ReactMarkdown` output itself when it's part of a larger component that re-renders frequently for unrelated state changes.
