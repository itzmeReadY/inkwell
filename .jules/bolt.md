## 2024-11-20 - Memoizing Expensive Markdown and KaTeX Rendering
**Learning:** Mixing computationally expensive components (like `ReactMarkdown` with `remarkMath` and `rehypeKatex`) alongside high-frequency state updates (like typing in a drawing layer or text box) causes massive performance degradation and typing lag. The problem was worsened because the `remarkPlugins` and `rehypePlugins` arrays were defined inline (`remarkPlugins={[remarkMath]}`), meaning their object identities changed on every single render, silently breaking any internal memoization in React.
**Action:** Always wrap expensive rendering components like `ReactMarkdown` with `React.memo` and define complex props like configuration arrays OUTSIDE the component scope or wrap them in `useMemo` so they preserve reference equality across renders.
