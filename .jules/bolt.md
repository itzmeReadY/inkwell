## 2024-05-24 - Cascading Re-renders in Inkwell Preview
**Learning:** The `App.tsx` manages state for typing in notes on the current page, updating on every keystroke. Because the `Preview.tsx` (which renders computationally expensive `react-markdown` and LaTeX equations via `katex`) received inline functions like `(md) => updateCurrentPage(md)` and inline default fallback arrays like `currentPage.textBoxes || []`, it failed referential equality checks and re-rendered on *every* keystroke. This causes severe lag during typing.
**Action:** Always wrap computationally expensive components in `React.memo`, but crucially, ensure the parent component passes stable props by extracting default arrays to constants outside the render loop (`const EMPTY_ARRAY = []`) and wrapping event handlers in `useCallback`.
